## 📖 About

PDF24 Creator is developed by Geek Software GmbH and has been a long running Windows utility for working with PDF documents. It installs a virtual PDF printer alongside a set of integrated tools: a document editor, a merge and split module, an OCR engine for scanned pages, a compressor for reducing file size, and converters that turn Office, image and text files into PDF. The 2026 edition refreshes the OCR engine, speeds up batch conversion and updates the printer driver for current Windows builds.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway** |
| Installer stalls at printer driver step | Close other print related apps, reboot, then run setup again as administrator |
| PDF printer missing after install | Open Settings, then Printers and scanners, and check that the PDF24 printer is listed and enabled |
| OCR output is not searchable | Set the correct document language in the OCR tool before starting recognition |
| Conversion job fails on large files | Split the document into smaller parts or increase the timeout in the toolbox settings |
| Editor opens slowly with scanned pages | Compress the file first to lower image resolution, then reopen it |
| Updates fail to apply | Download the current installer again and run it over the existing installation |
